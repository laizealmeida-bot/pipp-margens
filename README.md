# PIPP-Margens

Aplicativo offline/PWA do PIPP-Margens – Protocolo de Indicadores de Políticas Públicas em Contextos Periféricos.

## Arquivos

- `index.html`: aplicativo completo.
- `manifest.json`: configuração para instalação como app.
- `service-worker.js`: funcionamento offline.
- `icon.svg`: ícone do aplicativo.
- `LICENSE.md`: licença restritiva.
- `.nojekyll`: evita processamento pelo Jekyll no GitHub Pages.

## Como publicar no GitHub Pages

1. Extraia este ZIP.
2. Envie todos os arquivos para a raiz do repositório.
3. No GitHub, vá em **Settings > Pages**.
4. Em **Branch**, selecione `main` e `/root`.
5. Salve e aguarde o link ser gerado.
