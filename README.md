# pipp-margens
Protocolo de Indicadores de Políticas Públicas em Contextos Periféricos-PIPP-Margens. onsiste em um produto técnico-tecnológico desenvolvido a partir de evidênciasempíricas obtidas junto a artesãs de biojoias na Amazônia paraense, no âmbito de uma pesquisaancorada na teoria institucional e na perspectiva da reflexividade.
